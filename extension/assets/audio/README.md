# WebTNT 原创音效

这些音效来自 WebTNT 宣传片的同一套原创声音合成：点燃咔哒、火花燃烧、低频爆炸与随机碎裂、上行回吸与拼合提示音。素材不含宣传片背景音乐，也没有下载或使用第三方音频样本。代码和音效均按项目 [MIT 许可](../../../LICENSE) 提供。

| 文件 | 用途 | 时长 |
| --- | --- | --- |
| `ignite.wav` | 一次性点燃咔哒 | 0.045 秒 |
| `fuse.wav` | 燃烧火花循环；准备画面期间可继续播放 | 0.789708 秒 |
| `blast.wav` | 爆炸冲击与不对称碎片散落 | 1.3 秒 |
| `restore.wav` | 回吸风声、加速拼合、尾部提示音 | 0.675 秒 |

全部为 48 kHz、双声道、16-bit PCM WAV，保留峰值余量。`fuse.wav` 已移除单独的点燃咔哒，通过 60 毫秒等功率交叉混合处理循环接缝；其余音效添加短淡入或淡出，回吸音效末尾有 25 毫秒静音。完整规格、峰值、RMS 和文件 SHA-256 记录在 `audio-manifest.json`。

生成脚本为仓库中的 `tools/generate_audio.py`，仅生成时需要 NumPy；插件运行无需 Python、NumPy、网络或音乐播放器依赖。在仓库根目录运行：

```bash
python -m pip install numpy
python tools/generate_audio.py
```

脚本保存了宣传片第一组音效开始前的 PCG64 状态，独立重现原始音效后进行上述收尾处理，不需要原视频或临时制作目录。恢复音效包含宣传片中原有的 40 毫秒提前风声；播放器应从进入复原阶段时播放整个文件。
