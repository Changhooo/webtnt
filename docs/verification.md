## 在本地运行

需要 Node.js 22+：

```bash
npm ci
npm test
```

可选浏览器测试：

```bash
npx playwright install chromium
npm run test:browser
```

脚本默认使用生产配置。自动打开扩展弹窗可能无法授予 `activeTab`；授权受阻不代表效果测试通过。隔离模式 `TNT_QA_FIXTURE_PERMISSION=1` 临时复制配置、授予测试捕获权限并使用新资料目录，仅加载本地页，不修改生产扩展；仍不能替代真实工具栏授权和用户音频手势验收。

```powershell
$env:TNT_QA_FIXTURE_PERMISSION = "1"
npm run test:browser
Remove-Item Env:TNT_QA_FIXTURE_PERMISSION
```

结果写入 `tests/output/browser-results.json`；受阻退出码 2，失败 1，通过 0。

## 重建素材与打包

普通安装、测试和打包不需要 NumPy。仅重建声音时执行：

```bash
python -m pip install numpy
python tools/generate_audio.py
```

```bash
python tools/package.py --install-only --output dist/TNT_Blast_install.zip
python tools/package.py --output dist/TNT_Blast_source.zip
```

精简包第一层为 `manifest.json`，含本地音频播放器和全部 WAV；完整源码包的扩展位于 `extension`。脚本检查资源、生产权限、语法和 ZIP 完整性，排除依赖、产物和内部测试输出。GitHub Actions 执行同样测试和打包流程，远端结果以 Actions 页面为准。
