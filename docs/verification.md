## 在本地运行

需要 Node.js 22+：

```bash
npm ci
npm test
```

浏览器测试另需 Chromium：

```bash
npx playwright install chromium
npm run test:browser
```

脚本默认使用生产配置。自动打开扩展弹窗可能无法授予 `activeTab`；脚本会说明授权受阻，不能把这种情况当作效果测试通过。

可显式选择隔离测试模式 `TNT_QA_FIXTURE_PERMISSION=1`。该模式临时复制扩展配置，为测试授予画面捕获权限，使用新的浏览器资料目录，只加载本地测试页，不修改生产扩展。Windows PowerShell 示例：

```powershell
$env:TNT_QA_FIXTURE_PERMISSION = "1"
npm run test:browser
Remove-Item Env:TNT_QA_FIXTURE_PERMISSION
```

此模式检查渲染和交互，不能替代用户真实工具栏授权验收。结果写入 `tests/output/browser-results.json`；受阻退出码 2，失败 1，通过 0。

## 打包

```bash
python tools/package.py --install-only --output dist/TNT_Blast_install.zip
python tools/package.py --output dist/TNT_Blast_source.zip
```

精简安装包第一层是 `manifest.json`；完整源码包中的扩展位于 `extension`。脚本检查资源、生产权限、脚本语法和 ZIP 完整性，排除依赖、构建产物和内部测试输出。GitHub Actions 使用相同的测试与打包命令；远端运行结果以 Actions 页面为准。
