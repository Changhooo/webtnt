# TNT Blast 手动验收清单

建议先通过 `python -m http.server 8765` 打开 `http://localhost:8765/demo/`，加载 `extension` 目录后，从工具栏启用当前页。

## 性能观察

在一张普通长网页和一张包含动态内容的网页上，分别记录默认范围与最大范围下的流畅度，特别观察开启阴影与厚度后是否持续卡顿。使用浏览器任务管理器或开发者工具观察连续多次播放前后的内存及 CPU；关注动画结束后资源是否回落，而非只看瞬间峰值。

如果遇到问题，请记录 TNT 位置、范围、时长、页面类型及复现步骤。受保护视频、PDF 内置查看器和特殊全屏应单独标记兼容性，不能用占位区域或一次普通页面测试替代结论。
