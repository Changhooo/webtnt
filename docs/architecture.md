# TNT Blast 技术结构

## 当前范围

版本 1.0.7 是 Chrome／Edge Manifest V3 扩展。界面画面来自浏览器可见标签页捕获，动画在网页上的透明渲染层播放。Windows 桌面应用为后续计划，当前没有桌面程序或桌面安装包。

## 模块职责

| 模块 | 职责 | 与平台的关系 |
| --- | --- | --- |
| 扩展弹窗 | 用户启用、隐藏、关闭、还原和设置入口 | 浏览器专用 |
| 后台服务工作线程 | 接收截图请求、核对标签页与窗口状态、捕获可见画面 | 浏览器专用 |
| 网页控制器 | TNT 拖动、点击和菜单；视口监听；生命周期清理 | 浏览器专用 |
| 画面适配器 | 将截图和精确引爆落点转换为动画输入 | 可替换为桌面捕获适配器 |
| 爆炸渲染引擎 | 区域碎片、柔和阴影、厚度、不规则炸裂缺口、局部裂纹、冲击波、烟雾与回吸 | 尽量保持平台无关 |
| 设置与音效 | 参数校验、保存、时序和本机声音 | 设置存储可替换 |

## 引爆过程

1. 用户在浏览器工具栏启用扩展，向当前标签页注入悬浮控件。
2. 仅右键拖动更新固定 TNT 的位置。左键拖动创建独立、无虚线矩形框的 TNT 目标预览，固定图标保持原位；松开时记录精确鼠标落点，结束拖动预览，让同一个目标元素在该位置进入点燃阶段。单独右击保留菜单，右键拖动结束不误开菜单。
3. 左键松开或键盘点燃后进入引线阶段。目标位置的 TNT 闪烁、膨胀并出现火花，固定悬浮图标不搬到目标位置。
4. 临近爆炸时，目标继续保持燃烧状态。实际截图期间隐藏扩展控件的父层，并设置父层 `opacity: 0 !important`，避免显式可见的子元素泄漏进截图；原始截图返回后立即恢复父层，不等图片解码和碎片缓存完成。恢复后等待两个动画帧，保证准备目标获得绘制机会。
5. 依据视口大小与截图像素尺寸建立映射，从截图中提取爆炸周围区域。碎片保留该区域的实际视觉内容。异步解码及同步缓存准备期间目标仍显示，固定图标位置不变；取消后晚到的图像关闭并丢弃。
6. 引擎准备完成后，在同一同步调用中切换到散落并绘制首个闪光帧，再接替燃烧目标。通过覆盖层播放爆炸、散落和停留。影响随距离衰减，冲击从中心向外传播；缺口边缘形成不规则凹角、断裂切口与局部裂纹，碎片附带阴影与厚度。
7. 在复原阶段让碎片快速回吸，阴影与厚度逐步衰减至零；完成后清空覆盖层，露出原网页当前画面。固定 TNT 保持原位，目标与固定图标的坐标在整个周期中独立。

默认节奏为点燃 800 ms、散落 1000 ms、停留 2500 ms、复原 350 ms。截图与画面准备耗时另计，由浏览器和页面决定。设置可调整范围、强度和时长；音效默认关闭。

## 音效时序与素材

`audio.js` 播放安装包内 `assets/audio/` 的四个原创 WAV，与宣传片的 FX 来自同一套可复现合成源。素材通过扩展资源 URL 读取，列在 `web_accessible_resources` 中；不增加访问网站的常驻权限。默认静音，打开现有开关后预解码并缓存，用户点燃时在手势调用内恢复音频上下文。

控制器根据真实相位切换触发声音：`fuse` 播一次点燃咔哒并循环火花，`scatter` 接替循环并播放爆炸碎裂，`restore` 将完整回吸音效变速至当前 `restoreMs`。截图与碎片准备耗时不会让爆炸声提前。相同相位不重复触发，声像依据爆点的视口横坐标轻微左右偏移。

每次相位播放、取消及关闭都有独立播放世代校验。`stopAll()` 同步停止并断开当前节点，旧异步加载不能启动声音；缓存可留给下一次引爆。销毁时关闭音频上下文、中止挂起资源并释放缓存。资源、解码或自动播放失败只影响声音，不阻塞视觉效果。素材生成脚本是 `tools/generate_audio.py`，仅开发者重新生成时需要 NumPy。

## 提示文字设置

`showHints` 默认 `true`。悬浮工具栏的“文”按钮、工具栏弹窗的隐藏／显示文字按钮和网页设置面板复选框共用这一设置，保存到本机扩展存储，并在已启用的标签页之间同步。

该设置同时控制固定 TNT 与左键目标预览各阶段的下方提示，包括拖动与点燃期间的阶段文字。切换后现有控件立即更新，随后阶段生成的提示也遵循当前值；隐藏提示时保留按钮的悬停说明与 ARIA 可访问性标签。

## 原网页与视觉碎片

截图碎片是网页画面的临时副本。原网页不被拆卸或移除，表单和动态内容保持运行，渲染层结束时展示实时状态。普通文字、跨源图片、Canvas、嵌入页等内容是否能呈现，取决于浏览器实际捕获的画面；引擎无需进入 iframe 读取内部 DOM。

爆炸期间，覆盖区域可见的是捕获时刻的视觉副本。副本本身不是实时视频流；底层视频或动画可以继续推进，复原后显示其最新状态。受保护内容可能在截图中呈现空白。

除 TNT 和菜单外，覆盖层默认鼠标穿透。动画清理必须取消帧循环、移除临时图像引用、清空画布，并复原控件状态。用户按 Esc、手动还原、隐藏或关闭均应结束当前效果。

## 外缘裁边与投影

圆形截图裁边产生的细小切片保持与真实原网页连接，渲染层不将它们绘制为独立悬浮弧片，避免浅色弧片及其轻微位移、投影和厚度沿边界拼成圆环。外围碎片的投影与厚度按冲击强度衰减，冲击趋近零时也收敛到零。

这项处理保留圆形影响范围及中心碎片的飞散轨迹、柔和阴影、不规则缺口和自定义背景。复原时，所有飞散片的阴影与厚度仍完全消退。

## 坐标与生命周期

- 固定 TNT 的位置和左键目标坐标分别管理。右键拖动更新固定位置；左键拖动、点燃、爆炸与复原均不得改写它。目标预览跟随指针，爆心取鼠标松开时的准确视口坐标，不用固定图标中心或预览边界约束后的坐标替代。
- 引爆落点使用视口坐标；截图像素使用实际截图尺寸。两者按捕获时的视口尺寸换算，兼容设备像素比和浏览器缩放。
- 捕获是异步操作。开始捕获时的会话必须仍然有效，才可以启动动画；已经取消、关闭或被新会话替换的旧捕获结果不能重新显示效果。
- 滚动、缩放、窗口尺寸变化、标签页切换会取消当前爆炸，避免用过期截图覆盖新的画面。
- 进入全屏会隐藏 TNT，避免与全屏元素的顶层显示规则冲突。退出后由用户从弹窗重新启用。
- 网页刷新和导航后，用户可以再次从工具栏启用。扩展不依赖全站常驻脚本。

## 权限与数据

自定义背景存储在独立的 `tntBackground` 字段中，以限制尺寸的本地 JPEG 数据保存，不进入数值设置结构，不上传。控制器缓存解码图像并复用；替换、移除和关闭时释放资源，异步晚到的旧图不能复活已删除背景。引擎仅借用图像，不负责关闭控制器拥有的图像。

缺口标称大小为爆炸半径乘以 `craterRatio`，默认 0.65。此参数不改变碎片划分、飞散轨迹或爆炸强度。自定义图等比例 cover 裁切到缺口；没有图片时使用深色背景。两种背景均使用不规则破碎轮廓，边界包含凹角和断裂切口，并配合局部裂纹表现被冲击撕开的场景。缺口背景、断裂边缘与裂纹在复原阶段消退，结束后完整露出当前网页画面。

使用 `activeTab`、`scripting`、`storage`。用户启用当前页后才注入，不申请所有网站常驻权限。临时截图留在本机，用于当前效果；设置通过浏览器扩展存储保存。动画不需要网络上传、后端或账号。

`chrome://`、`edge://`、扩展商店和部分浏览器内置页面受平台限制。权限被拒绝、网页不能注入或捕获失败时，应显示可理解的状态，并退出临时动画。

## 性能控制

渲染应限制受影响区域、碎片数量和粒子数量，使用一次截图而非持续捕获整个屏幕。柔和碎片阴影预先缓存，在动画帧中复用，避免为每片碎片每帧重复生成模糊。碎片的位移、旋转、透明度与回吸按时间计算，避免低帧率改变动画总时长。厚度表现与阴影在复原时随进度衰减，复原完成为零；清理时清空画布和临时缓存引用。页面隐藏时及时取消效果，避免后台资源持续占用。

本地测试页以文字、表单、SVG、时钟、Canvas、iframe 和四秒循环视频覆盖不同画面类型；实际视频网站与特殊全屏需在目标网页另外验收。测试方法见 [manual-checklist.md](manual-checklist.md)。

## Windows 迁移计划

| 保留 | 替换或新增 |
| --- | --- |
| 爆炸状态、时间曲线、碎片生成、粒子与回吸逻辑 | 可见桌面／窗口画面捕获 |
| 爆炸范围、效果强度、默认时长与音效 | 原生透明置顶窗口及点击穿透 |
| 临时图像输入与清理约定 | 屏幕坐标、多显示器、负坐标和 DPI 换算 |
| 本机处理、不上传截图 | 系统托盘、全局快捷键、桌面设置存储 |

桌面版的画面捕获、悬浮窗口技术及打包方式应在 Windows 环境中验证后确定。普通桌面与应用窗口为优先范围；独占全屏、受保护画面、系统安全桌面等场景有平台限制，不能将“任何界面”视为已实现的兼容性结论。
